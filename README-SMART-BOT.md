# 🤖 업비트 스마트 스캘핑 봇 v2.0

## 🎯 핵심 기능

✨ **진행 중인 코인 자동 감지**
- 수동으로 매수한 코인을 자동으로 찾아냄
- 여러 코인을 동시에 관리 가능

🧠 **모든 행동에 설명 + 이유**
- "왜 매수/매도하는지" 상세히 설명
- RSI, 볼린저밴드, 피보나치 근거 제시
- 초보자도 이해하기 쉬운 로그

🔒 **로컬 전용 (보안)**
- API 키를 파일로 관리 (Git에 안 올라감)
- 출금 권한 없이 안전하게 운영

📊 **전략 기반 자동 매매**
- Bollinger Bands + RSI + Fibonacci
- 분할 매수/매도로 리스크 분산
- 목표 수익 & 손절 자동 관리

---

## 🚀 5분 만에 시작하기

### 1️⃣ 패키지 설치
```bash
pip install pyupbit pandas numpy
```

### 2️⃣ API 키 설정
```bash
# 템플릿 복사
cp api_keys.json.example api_keys.json

# 편집
nano api_keys.json
```

**`api_keys.json` 내용:**
```json
{
  "access_key": "업비트에서_발급받은_Access_Key",
  "secret_key": "업비트에서_발급받은_Secret_Key"
}
```

📖 **자세한 방법**: [`API-KEYS-SETUP.md`](API-KEYS-SETUP.md)

### 3️⃣ 봇 실행
```bash
# 방법 1: 직접 실행
python3 upbit-smart-bot.py

# 방법 2: 스크립트로 실행 (권장)
./start-smart-bot.sh
```

## 🎛️ 전략 요약

### 매수 조건 (3개 이상)
- RSI < 30 (과매도)
- RSI < 40 (저평가)
- 가격 ≤ 볼린저 하단 × 1.01
- 평단가 ≤ 피보나치 50%

### 매도 조건 (3개 이상)
- 수익률 ≥ 1.5% (목표 달성)
- 수익률 ≤ -3.0% (손절)
- RSI > 70 (과매수)
- RSI > 60 (고평가)
- 가격 ≥ 볼린저 상단 × 0.99

### 분할 매매
- **매수**: 원화의 20%씩
- **매도**: 수량의 20%씩

## ⚠️ 주의사항

### 시뮬레이션 모드 (기본)
봇은 기본적으로 **시뮬레이션 모드**로 실행됩니다.
- 실제 주문이 실행되지 않음
- 로그에만 주문 내역이 기록됨

### 실전 모드 활성화
`upbit-smart-bot.py` 파일에서 주석 해제:

```python
# 주석 해제 (약 340번째 줄)
order = upbit.buy_market_order(ticker, buy_amount)
log(f"✅ 매수 완료: {order}", "SUCCESS")

# 주석 해제 (약 360번째 줄)
order = upbit.sell_market_order(ticker, sell_amount)
log(f"✅ 매도 완료: {order}", "SUCCESS")
```

⚠️ **실전 모드는 실제 돈이 거래됩니다!**
- 먼저 시뮬레이션으로 충분히 테스트
- 소액(10만원)으로 실전 테스트

## 📞 문제 해결

### "api_keys.json 파일이 없습니다"
→ [`API-KEYS-SETUP.md`](API-KEYS-SETUP.md) 참고

### "ModuleNotFoundError"
```bash
pip install pyupbit pandas numpy
```

### 봇이 주문을 안 함
- **정상**: 매수/매도 조건 미충족 시 관망
- **확인**: 로그의 "전략 판단" 부분 읽기
