## 🔑 4단계: API 키 입력 (1분)

### 4-1. 업비트 API 키 발급
1. **업비트 웹사이트** 접속: https://upbit.com
2. 로그인 → **마이페이지** → **Open API 관리**
3. **API 키 발급** 클릭
4. **권한 설정**:
   - ✅ **자산 조회**
   - ✅ **주문 조회**
   - ✅ **주문하기**
   - ❌ **출금하기** (절대 체크 금지!)
5. **발급 완료** → Access Key, Secret Key 복사

### 4-2. 웹 대시보드에 입력
1. 대시보드 우측 상단 **⚙️ 설정** 클릭
2. **Access Key** 붙여넣기
3. **Secret Key** 붙여넣기
4. **저장** 클릭 ✅

```
⚙️ API 키 설정

Access Key: [여기에 붙여넣기]
Secret Key: [여기에 붙여넣기]

⚠️ 보안 주의
• API 키는 브라우저에 저장되지 않습니다
• 서버의 api_keys.json 파일에만 저장됩니다
• 출금 권한은 절대 활성화하지 마세요

[취소] [저장]
```

## 🔧 자주 묻는 질문 (FAQ)

### Q1. 봇이 거래를 안 해요
**A1. 시뮬레이션 모드로 실행 중입니다**
- 안전을 위해 기본적으로 시뮬레이션 모드입니다
- **실전 모드 전환**: 
  1. `upbit-smart-bot-v5.py` 파일을 메모장으로 열기
  2. Ctrl+F로 `# order =` 검색
  3. 주석(`#`) 제거하여 주문 활성화
  4. 저장 후 봇 재시작

```python
# 시뮬레이션 (주문 안 됨):
# order = upbit.buy_market_order(ticker, buy_amount)

# 실전 모드 (주문 실행):
order = upbit.buy_market_order(ticker, buy_amount)
```

### Q2. 봇을 끄려면 어떻게 하나요?
**A2. 두 가지 방법**
1. **웹 대시보드**: **⏸ 봇 중지** 클릭
2. **터미널 창**: Ctrl+C 누르기

### Q3. 다시 시작하려면?
**A3. 원클릭 재시작**
- **Windows**: `setup-wizard.bat` 더블 클릭
- **Mac**: `setup-wizard.sh` 더블 클릭

### Q4. API 키를 변경하려면?
**A4. 웹 대시보드에서 수정**
1. **⏸ 봇 중지** 클릭
2. **⚙️ 설정** 클릭
3. 새로운 API 키 입력 → **저장**

### Q5. 수익금이 자동으로 투자되나요?
**A5. 네, 자동입니다**
- 3단계 익절 완료 시 수익금 확인
- 1만원 이상이면 자동으로:
  1. SOL 1만원 매수
  2. 다음 익절 시 XRP 1만원 매수
  3. 그 다음 BTC 1만원 매수
  4. 마지막으로 HBAR 1만원 매수

### Q6. 초기 시드가 줄어들면 어떻게 되나요?
**A6. 자동으로 매수 차단**
- 원화 잔고가 초기 시드보다 적으면 추가 매수 금지
- 대시보드에 경고 배너 표시:
  ```
  🛡️ 시드 보호: 매수 금지 (현재: 180,000원 < 시드: 200,000원)
  ```

### Q7. 24시간 계속 켜둬야 하나요?
**A7. 원하는 만큼 실행**
- 24시간 실행 가능 (PC를 켜둬야 함)
- 중간에 끄고 켜도 괜찮음
- 봇을 끄면 거래 중지

### Q8. 여러 PC에서 사용 가능한가요?
**A8. 동시 실행 불가**
- 하나의 API 키로 여러 PC에서 동시 실행 시 충돌
- 한 PC에서만 사용 권장

## 📞 문제 해결

### 문제 1: Python을 설치했는데도 "Python이 없다"고 나옴
**해결**:
1. Python 재설치 시 **"Add Python to PATH"** 체크 확인
2. CMD 창을 **모두 닫고** 다시 열기
3. `python --version` 입력 → 버전이 나오면 성공

### 문제 2: 라이브러리 설치 오류
**해결**:
```bash
pip install --upgrade pip
pip install pyupbit pandas numpy flask flask-cors --force-reinstall
```

### 문제 3: 웹 대시보드가 안 열려요
**해결**:
1. 브라우저에서 직접 입력: `http://localhost:5000`
2. 방화벽이 차단하는지 확인
3. 포트 5000이 사용 중인지 확인

### 문제 4: "업비트 연결 실패"
**해결**:
1. API 키가 올바른지 확인
2. 업비트 Open API 관리에서 IP 제한 확인
3. 권한 설정 확인 (자산 조회, 주문 조회, 주문하기)
