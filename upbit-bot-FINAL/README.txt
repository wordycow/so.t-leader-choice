🤖 업비트 스마트 봇 v5.0
====================================

📦 사용법 (2단계)
====================================

1️⃣ INSTALL.bat 더블 클릭 (처음 한 번만)
   → 필수 라이브러리 자동 설치 (3분)

2️⃣ START.bat 더블 클릭 (매번)
   → 웹 브라우저 자동 열림
   → API 키 입력
   → [▶ 봇 시작] 클릭


🛑 봇 중지
====================================

• 웹에서 [⏸ 봇 중지] 클릭
• 또는 터미널 창 닫기
• 또는 Ctrl+C


⚠️ Python 필요
====================================

Python이 설치되어 있어야 합니다.

확인: 명령 프롬프트(cmd)에서
python --version

설치: https://www.python.org/downloads/
(설치 시 "Add Python to PATH" 체크!)


✅ 핵심 기능
====================================

💰 5단계 분할 매수 (6k → 10k×3 → 100k)
📈 3단계 분할 익절 (50%, 30%, 20%)
💎 수익 자동 재투자 (SOL, XRP, BTC, HBAR)
🛡️ 시드 보호 (초기 자본 절대 보존)
🌐 웹 대시보드 (실시간 모니터링)
