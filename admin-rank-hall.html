rank-hall.json 열기
텍스트 붙여넣기 → 멤버 자동 반영
한 줄에 1명. 형식: [L]KR-10076355 / 심승철 / 스타I
- [L] 같은 태그는 무시
- KR-10076355 → id로 저장(동명이인 구분용)
- 직급이 비어있으면 자동으로 MEMBER
- 스타I/스타Ⅰ/STAR I 입력은 자동으로 STAR1로 정리
직급자 편집
- id: 게이트에서 쓰는 아이디(시트 아이디)와 동일하게(소문자 권장)
- rank: 예) STAR3 / PRO2 / STAFF / MEMBER
- note: 직급자 노트(한 줄 또는 여러 줄)
