🤖 업비트 스마트 봇 v5.0
========================================

✅ 지금 바로 실행하기
========================================

명령 프롬프트(cmd)에서:

python -m pip install --user flask flask-cors pyupbit pandas numpy requests
python upbit-smart-bot-v5.py

→ 웹 브라우저 자동 열림!


📦 정식 설치 방법
========================================

1️⃣ INSTALL.bat 더블 클릭 (처음 한 번만)
   → 모든 라이브러리 자동 설치 (3분)

2️⃣ START.bat 더블 클릭 (매번)
   → 웹 브라우저 자동 열림
   → API 키 입력
   → [▶ 봇 시작] 클릭


🛑 봇 중지
========================================

• 웹: [⏸ 봇 중지] 버튼 클릭
• 터미널 창 닫기
• Ctrl+C


⚠️ Python 필수
========================================

Python 설치: https://www.python.org/downloads/

✨ 핵심 기능
========================================

📈 3단계 분할 익절: 50% @ +2.5%, 30% @ +2.0%, 20% @ +1.5%
💎 수익 재투자: SOL, XRP, BTC, HBAR (각 1만원)
