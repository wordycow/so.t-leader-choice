## 📂 바탕화면에 복사할 파일

다음 3개 파일을 **바탕화면**에 복사하세요:

```
v9/바탕화면_시작.bat     → 바탕화면으로 복사
v9/바탕화면_종료.bat     → 바탕화면으로 복사
v9/바탕화면_재시작.bat   → 바탕화면으로 복사
```

### 📥 복사 방법
1. `C:\Windows\System32\webapp\v9` 폴더 열기
2. 위 3개 파일 선택
3. **Ctrl+C** (복사)
4. 바탕화면에서 **Ctrl+V** (붙여넣기)

## ⚙️ 경로 수정 방법

### 🔧 프로젝트 경로가 다른 경우

기본 경로: `C:\Windows\System32\webapp\v9`

만약 프로젝트가 **다른 경로**에 있다면:

1. 바탕화면의 `바탕화면_시작.bat` 파일을 **우클릭** → **편집**
2. **9번째 줄** 찾기:
   ```batch
   set PROJECT_DIR=C:\Windows\System32\webapp\v9
   ```
3. 실제 경로로 수정:
   ```batch
   set PROJECT_DIR=D:\MyProjects\upbit-bot\v9
   ```
4. 저장 후 닫기
5. **같은 방법**으로 `바탕화면_종료.bat`, `바탕화면_재시작.bat`도 수정

### 📝 예시

| 실제 프로젝트 경로 | 수정할 내용 |
|-------------------|-------------|
| `C:\Users\유송\Documents\webapp\v9` | `set PROJECT_DIR=C:\Users\유송\Documents\webapp\v9` |
| `D:\Projects\bot\v9` | `set PROJECT_DIR=D:\Projects\bot\v9` |
| `E:\trading-bot\v9` | `set PROJECT_DIR=E:\trading-bot\v9` |

## 🚀 실행 방법

### 1️⃣ **시작**
바탕화면의 `바탕화면_시작.bat` 더블클릭

```

   1. Cloudflare Tunnel

   6. IMEI System
```

바탕화면의 `바탕화면_종료.bat` 더블클릭

```
✅ UAC 팝업 → "예" 클릭
✅ 모든 프로세스 종료
✅ 자동 상태 확인
```

### 3️⃣ **재시작**
바탕화면의 `바탕화면_재시작.bat` 더블클릭

```
✅ UAC 팝업 → "예" 클릭
✅ 종료 → 5초 대기 → 재시작
✅ 브라우저 자동 오픈
```

## ⚠️ 문제 해결

### ❌ "프로젝트 폴더를 찾을 수 없습니다" 오류

**원인:** PROJECT_DIR 경로가 잘못됨

**해결:**
1. 실제 프로젝트 경로 확인
2. 배치 파일 편집 (우클릭 → 편집)
3. `set PROJECT_DIR=` 부분을 실제 경로로 수정

### ❌ "Python이 설치되지 않았습니다" 오류

**원인:** Python이 없거나 PATH에 등록되지 않음

**해결:**
1. Python 설치: https://www.python.org/downloads/
2. 설치 시 **"Add Python to PATH"** 체크 필수
3. CMD에서 `python --version` 확인

### ❌ "Ollama가 설치되지 않았습니다" 오류

**원인:** Ollama가 설치되지 않음

**해결:**
1. Ollama 설치: https://ollama.com/download
2. 설치 후 CMD에서 `ollama --version` 확인

### ❌ "Cloudflared가 설치되지 않았습니다" 오류

**원인:** Cloudflared가 설치되지 않음

**해결:**
1. Cloudflared 설치: https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
2. 설치 후 CMD에서 `cloudflared --version` 확인

### ❌ "관리자 권한이 필요합니다" 오류

**원인:** UAC 팝업을 거부함

**해결:**
1. 배치 파일 **우클릭** → **관리자 권한으로 실행**
2. 또는 UAC 팝업에서 **"예"** 클릭
